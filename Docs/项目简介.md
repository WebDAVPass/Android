6. 横屏布局相关资源文件
项目中不存在 layout-land 目录。 我通过 glob 搜索 **/layout-land/** 和 **/*land* 均无结果。

原因：该项目完全基于 Jetpack Compose 构建 UI，不使用传统 XML 布局。Compose 本身通过 LocalConfiguration.current 和自适应布局（如 BoxWithConstraints、WindowWidthSizeClass）来处理屏幕方向变化，无需 layout-land 目录。

项目中现有的 res/layout/ 目录仅包含 11 个 XML 文件，全部服务于 AutoFill 服务（系统自动填充框架要求的 RemoteViews），与主应用 UI 无关。

7. 导航相关代码
7.1 导航系统架构
本项目使用 AndroidX Navigation3 配合自定义 Navigator（非 Navigation Compose），整体为单 Activity 架构。

文件路径	作用

7.2 路由定义（Routes.kt）
kotlin
sealed interface Route : NavKey, Parcelable {
    data object Home : Route              // 首页（四宫格）
    data object Settings : Route          // 设置主索引
    data object DatabaseSettings : Route  // 数据库设置
    data object GeneralSettings : Route   // 通用设置
    data object SecuritySettings : Route  // 安全设置
    data object BackupSettings : Route    // 备份设置
    data object About : Route             // 关于
    data object Welcome : Route           // 欢迎页（库选择）
    data object Locked : Route            // 锁定页
    data object TokenList : Route         // 令牌列表
    data object SecurityCheck : Route     // 安全性检查
    data class PasswordList(val listMode: PasswordListMode) : Route      // 密码列表
    data class PasswordEntryDetail(val entryId: Long) : Route            // 密码详情
}
7.3 导航流程
冷启动初始路由：存在已记录的库 -> Route.Locked；否则 -> Route.Welcome
Welcome -> 解锁/创建/选择库 -> Route.Home
Locked -> 输入主密码解锁 -> Route.Home
Home 四宫格导航：
"密码" 卡片 -> Route.PasswordList(ALL_PASSWORDS)
"动态令牌" 卡片 -> Route.TokenList
"安全性" 卡片 -> Route.SecurityCheck
"最近删除" 卡片 -> Route.PasswordList(RECENT_DELETED)
PasswordList -> 点击条目 -> Route.PasswordEntryDetail(entryId)
Settings 有子路由：DatabaseSettings、GeneralSettings、SecuritySettings、BackupSettings、About
7.4 Navigator 实现（Navigator.kt）
基于 mutableStateListOf<NavKey> 实现回退栈
支持 push/pop/replace/replaceAll/popUntil 操作
内置 navigateForResult / setResult / observeResult 跨页面通信机制（基于 SharedFlow）
通过 Saver 实现配置变更（旋转等）时的回退栈持久化
通过 CompositionLocalProvider(LocalNavigator provides navigator) 注入到组合树
7.5 安全守卫
每个需要解锁状态的路由（Home、PasswordList、PasswordEntryDetail、Settings、TokenList、SecurityCheck 等）都在其 entry<> 块中包含 LaunchedEffect(isLibraryUnlocked, lib) 守卫，在库被锁定或清除时自动导航回 Route.Locked 或 Route.Welcome。
